# Security policy

## Supported versions

While DeckBridge is in Preview, security fixes are provided for the latest published version only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for `dtrajano/deckbridge`. Do not disclose security issues in a public issue and do not include real credentials, prompts, transcripts or private source code.

DeckBridge executes the locally configured Agent Deck CLI and interacts with local session data. Reports about Agent Deck itself or an agent provider should be sent to the relevant upstream project.
