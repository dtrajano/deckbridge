# Changelog

All notable changes to DeckBridge are documented here.

## 0.2.1 - 2026-10-25

### Fixed

- Use a stable public README image URL in the Marketplace renderer.
- Remove opaque white corners from the Marketplace icon.

## 0.2.0 - 2026-10-18

### Added

- Sidebar session browser with Agent Deck grouping and live status indicators.
- Structured chat history, live updates and prompt sending through Agent Deck Recall.
- Session creation, rename, grouping, start, stop, restart and terminal attachment.
- Tool, model, mode, context usage and full session metadata in the chat.
- Guided slash-command and Agent Deck skill completions, including interactive model selection.
- VS Code test execution and Test Explorer integration.
- Agent Deck installation detection and configurable executable paths.

### Notes

- This is the first public Preview release.
- File attachments and rich Markdown rendering remain planned for a future version.
