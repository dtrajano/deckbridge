# Support

Use [GitHub Issues](https://github.com/dtrajano/deckbridge/issues) for DeckBridge bugs and feature requests.

Before opening an issue:

1. Run `agent-deck version` in the same environment as VS Code.
2. Run **DeckBridge: Check Agent Deck Installation**.
3. Confirm that Agent Deck Recall is enabled.
4. Include your operating system, VS Code version, DeckBridge version, Agent Deck version and agent tool.

Do not attach transcripts, credentials, tokens or private source code. Agent Deck itself is maintained separately; report its CLI-specific problems to the upstream project.
